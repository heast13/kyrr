Rausch­unterdrückung und Diktat für Windows und Linux

kyrr ist eine kostenlose Open-Source-App. Sie entfernt Störgeräusche aus deinem Mikrofon und wandelt Sprache in Text um, auf Deutsch und Englisch. Der gesamte Ton wird auf deinem Computer verarbeitet.

Schmatzfrei

Funktionen

Rauschunterdrückung

Entfernt Hintergrundgeräusche wie Tippen, Lüfter oder Verkehr in Echtzeit aus dem Mikrofonsignal. kyrr nutzt dafür das neuronale Netz DPDFNet, mit einem großen Modell und einem kleinen, das weniger Rechenleistung braucht. Apps wie Teams, Zoom, Discord, OBS oder der Browser bekommen den bereinigten Ton, ohne dass du dort etwas einstellen musst.

Stimmbearbeitung

Filter gegen tiefes Rumpeln, Klang-Voreinstellungen (Neutral, Warm, Klar, Hell oder eigene), Kompressor, De-Esser, Popschutz und automatische Lautstärke. Voreingestellt: neutraler Klang, mittlere Kompression, leichte S-Laut-Dämpfung, Rumpelfilter und automatische Lautstärke. Alles lässt sich in den Einstellungen ändern.

Diktat

Halte F9 gedrückt, während du sprichst. Beim Loslassen tippt kyrr den Text an der Cursorposition ein, in der App, in der du gerade schreibst. Deutsch und Englisch. „Neue Zeile“ fügt einen Zeilenumbruch ein. Statt F9 gehen auch F8, Pause oder Strg rechts, oder einmal tippen zum Starten und einmal zum Beenden.

Pegelkontrolle

Anzeigen zeigen, was das Mikrofon aufnimmt und was bei den Apps ankommt. Ein Zehn-Sekunden-Test nimmt deine Stimme auf und spielt sie vor und nach der Bearbeitung ab. Du kannst dich auch live über Kopfhörer mithören.

Funktionsweise

  1. Installation. Windows: ein Installationsprogramm, das Administratorrechte braucht. Linux: eine einzelne AppImage-Datei, ohne Administratorrechte. Beim ersten Start richtet sich kyrr selbst ein.
  2. Ton. Unter Windows fügt kyrr dem Windows-Audiosystem einen Filter hinzu, der direkt am Mikrofon arbeitet. Unter Linux legt kyrr ein PipeWire-Mikrofon namens „kyrr“ an und macht es zum Standard. Deine Apps brauchen keine Änderung. Wechselst du das Mikrofon, wechselt kyrr mit.
  3. Diktat. Beim ersten Diktieren lädt kyrr einmalig das Sprachmodell für deine Sprache herunter (Deutsch 900 MB, Englisch 663 MB). Danach funktioniert das Diktat offline.
  4. Updates. kyrr sucht einmal täglich nach einer neuen Version und zeigt sie an. Unter Windows installiert „Aktualisieren“ sie. Unter Linux beendest du kyrr und führst die Installationsbefehle erneut aus.

Datenschutz

Ton und Text werden nur auf deinem Computer verarbeitet. kyrr braucht kein Konto und sendet keine Nutzungsdaten.

kyrr verbindet sich für drei Dinge mit dem Internet: einmal zum Herunterladen des Sprachmodells (jede Datei wird per SHA256-Prüfsumme kontrolliert), täglich zur Update-Suche bei GitHub (in den Einstellungen abschaltbar) und zum Herunterladen eines Updates, wenn du auf „Aktualisieren“ klickst. System­anforderungen

Windows

  • Windows 10 (22H2) oder Windows 11, 64 Bit
  • Intel- oder AMD-Prozessor. Unter Windows auf ARM funktioniert nur das Diktat.
  • Administratorrechte für die Installation

Linux

  • 64 Bit Intel oder AMD, glibc 2.39 oder neuer: Ubuntu 24.04, Fedora 40, Debian 13, Linux Mint 22, Arch oder neuer
  • PipeWire. Ist es nicht installiert, bietet kyrr die Installation an.
  • Die Rauschunterdrückung braucht einen Prozessor mit AVX2 (die meisten ab 2015).

Beide: keine Grafikkarte nötig. Speicherplatz für das Sprachmodell: 663 MB (Englisch) oder 900 MB (Deutsch).

Beim Anmelden starten

kyrr startet automatisch beim Anmelden, sobald die Einrichtung beim ersten Start fertig ist. Ändern: Einstellungen in kyrr, „Mit Windows starten“.

Linux (Beta)

Die Linux-Version ist noch eine Beta: Sie läuft, ist aber auf weniger Systemen getestet als die Windows-Version.

Kopier das in ein Terminal. Es lädt kyrr nach ~/.local/bin, macht es ausführbar und startet es:

mkdir -p ~/.local/bin
curl -L -o ~/.local/bin/kyrr https://github.com/heast13/kyrr/releases/latest/download/kyrr-x86_64.AppImage
chmod +x ~/.local/bin/kyrr
~/.local/bin/kyrr &

Ohne Terminal: AppImage herunterladen, im Dateimanager als Programm ausführen erlauben (Rechtsklick, Eigenschaften) und doppelklicken. Beim ersten Start legt kyrr einen Eintrag im App-Menü an. Unter GNOME ab 48 und KDE fragt der Desktop einmal nach der Diktier-Taste und einmal, ob kyrr tippen darf; kyrr erklärt beide Schritte. Hinweise zu anderen Desktops (Englisch)

Deinstallieren

kyrr beenden („Beenden“, unten links), dann einfügen:

rm -f ~/.local/bin/kyrr \
  ~/.config/autostart/io.github.heast13.kyrr.desktop \
  ~/.local/share/applications/io.github.heast13.kyrr.desktop \
  ~/.local/share/icons/hicolor/256x256/apps/io.github.heast13.kyrr.png \
  ~/.local/share/icons/hicolor/scalable/apps/io.github.heast13.kyrr.svg
rm -rf ~/.config/kyrr ~/.local/share/kyrr

Die letzte Zeile löscht auch deine Einstellungen und die Sprachmodelle. Lass sie weg, wenn du sie behalten willst.

Fragen

Braucht kyrr eine Internetverbindung?

Nur zum Herunterladen des Sprachmodells beim ersten Diktieren, für die tägliche Update-Suche, die du abschalten kannst, und zum Herunterladen eines Updates, wenn du auf „Aktualisieren“ klickst. Die Rauschunterdrückung funktioniert ohne Internet.

Wie lang darf ein Diktat sein?

Bis zu 15 Minuten. Was darüber hinausgeht, wird nicht mehr aufgenommen.

Welche Apps bekommen den bereinigten Ton?

Unter Windows jede App, die das Mikrofon nutzt. Unter Linux jede App, die das Standardmikrofon nutzt; kyrr stellt dafür sein eigenes Mikrofon „kyrr“ als Standard ein.

Gibt es eine Mac-Version?

Nein. kyrr gibt es für Windows und Linux.

Was unterscheidet kyrr von NVIDIA Broadcast und Krisp?

NVIDIA Broadcast braucht eine NVIDIA-RTX-Grafikkarte. Krisp braucht ein Konto und ist 60 Minuten pro Tag kostenlos, danach nur mit Abo. Beide arbeiten als virtuelles Mikrofon, das du in jeder App auswählst. Bei kyrr ist in den Apps keine Auswahl nötig: Unter Windows filtert es das Mikrofon selbst, unter Linux stellt es sein eigenes Mikrofon als Standard ein. kyrr braucht kein Konto und hat zusätzlich ein Diktat. Ist kyrr fertig?

kyrr wird aktiv weiterentwickelt. Fehlermeldungen und Vorschläge bitte über GitHub.

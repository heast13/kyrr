Linux

Paste this into a terminal:

mkdir -p ~/.local/bin
curl -L -o ~/.local/bin/kyrr https://github.com/heast13/kyrr/releases/latest/download/kyrr-x86_64.AppImage
chmod +x ~/.local/bin/kyrr
~/.local/bin/kyrr &

For current 64-bit distributions with PipeWire (Ubuntu 24.04+, Fedora, Arch and friends). Prefer clicking? Get the file, allow it to run as a program, double click. Uninstall and other details: README

Questions

Does it need the internet?

Only once, to download the speech model. After that kyrr works offline.

Do I need a fancy computer?

No. Any 64-bit PC with Intel or AMD will do, no graphics card needed. A small filter is there for older laptops.

Which languages?

German and English.

What does it cost?

Nothing. It's free and open source, and there is no account to make.

How is it different from NVIDIA Broadcast or Krisp?

Broadcast needs an RTX graphics card, Krisp an account and, for full use, a subscription. kyrr needs neither, and it types what you say on top. As far as we know in October 2026; corrections welcome.
